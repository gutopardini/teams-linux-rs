# Teams Linux development

- Build the desktop application in Rust with Iced and wgpu.
- Exercise changes with `--demo`, synthetic fixtures, and local servers. Use
  sample data in screenshots and issue reports. Keep work-account data,
  credentials, and raw captures out of commits and logs.
- Keep protocol identifiers separate from translated text. Use the catalog in
  `locales/` for interface strings.
- Record the checks you ran in the pull request. For a visual change include a
  reproducible demo command, and for a parser change exercise representative
  input and failure paths.
