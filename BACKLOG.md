# Roadmap

GitHub issues track current work and requests. For a small contribution, start
with a reproducible chat problem, a missing translation, or a synthetic test
for supported message content.

| Area | Current priorities |
| --- | --- |
| Chat | Rich message formats, attachment previews, search, and accessibility |
| Calls and meetings | Incoming audio stability, remote video, and camera and screen sharing on more Linux setups |
| Calendar | Loading and error recovery, meeting details, and recurring events |
| Linux desktop | Packaging, keyboard navigation, and testing on Wayland and X11 |
| Localization | Complete English and Brazilian Portuguese coverage, and add more languages |

See [how to contribute](README.md#contribute) for the demo and local tests.
